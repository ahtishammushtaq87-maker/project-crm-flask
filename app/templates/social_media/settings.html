Security

{{ m.badge('ok' if enc[0] == 'ok' else 'error', 'encryption ' ~ enc[0]) }}

{{ enc[1] }}

{% if enc[0] != 'ok' %}
  1. On the server, generate a key:
    {{ m.copy('python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"') }}
  2. Set it as the environment variable SOCIAL_MEDIA_ENCRYPTION_KEY for the CRM process (hosting dashboard, systemd unit or service manager). Keep a secure backup — without it, saved credentials cannot be decrypted.
  3. Restart the CRM.
{% endif %}
  • App secrets and access tokens are encrypted with Fernet (AES + HMAC) using a key kept outside the database; they are never sent to the browser or written to logs.
  • OAuth uses a random, single-use, 10-minute state bound to your CRM session; callbacks must arrive on the configured redirect URI.
  • Every page and action checks Social Media permissions on the server. Accounts can be restricted to specific users.
  • All account, publishing, settings and advertising actions are written to the activity log with user, time and result; tokens are redacted.
