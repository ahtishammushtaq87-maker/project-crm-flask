Instructions
  • Download the sample sheet below first - it already shows exactly how to fill it in, with a second tab ("Read Me First") explaining every column.
  • Only name is required. Every other column is optional.
  • Leave parent_name blank to create a main category. To create a sub-category, put the exact name of an existing main category in parent_name - add that main category as its own row too (it doesn't matter which row comes first).
  • The five allow_* columns just take Yes or No - they control which special options (Invoice/Purchase Payment, Inventory Shift, BOM Overhead, Monthly Division) are offered on Add/Edit Expense when that category is picked.
  • Category names must be unique. A row whose name already exists (in the system, or repeated earlier in the same sheet) is simply left as-is and skipped - it is never duplicated or overwritten. Every other new row in the file is still uploaded, and the result page lists exactly which rows were added, which were skipped as already existing, and which had an error.
