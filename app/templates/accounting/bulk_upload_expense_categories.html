Instructions
  • Download the sample sheet below first - it shows exactly how to fill it in (tab "Bulk Upload"), with a second tab ("Read Me First") explaining every column. If your workbook has other tabs too, the "Bulk Upload" tab is the one read.
  • Columns: name, parent_name, description, allow_invoice_payment, allow_purchase_payment, allow_inventory_shift, allow_bom_overhead, allow_monthly_divided, allow_pd_shift. Only name is required; a column left out of the sheet is left unchanged on existing categories.
  • Leave parent_name blank for a main (parent) category. For a sub-category, put its parent's exact name in parent_name and add the parent as its own row too (row order doesn't matter). A parent that's only referenced, never given its own row, is auto-created (name only) and listed on the result page.
  • The allow_* columns take Yes or No. They can be set on the parent (applies to all its sub-categories) and/or on each sub-category - a sub-category gets its parent's options plus its own.
  • No duplicates: names are matched ignoring upper/lower case and extra spaces. A name that already exists updates that category (description, options, and it is moved under the parent_name in the sheet) instead of being added again. A name repeated within the sheet is applied once and the repeat is reported.
  • The result page shows a count for every row - added, updated, moved and errors - so you can confirm nothing was missed.
A Draft category is hidden from Add/Edit Expense. When ticked, every category in the sheet that is currently in Draft is taken out of Draft so it can be used. {% if current_user.is_admin %}As an admin, every category in your upload is Approved automatically.{% else %}It then waits for admin approval.{% endif %}
