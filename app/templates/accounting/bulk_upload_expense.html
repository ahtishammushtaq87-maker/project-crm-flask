Instructions
  • Upload an Excel file (.xlsx or .xls). Columns are matched by name (case-insensitive), in any order.
  • Required columns: Date, Category, Description, Amount
  • Optional columns: Expense #, Vendor, Approval
  • Category / Vendor are matched by name — if a name isn't found yet, it's created automatically.
  • Expense #: leave blank to always create a new expense. If it matches an existing expense number, that expense is updated instead of duplicated.
  • Approval: one of Pending, Approved, Rejected, Draft. Only admins can set Approved/Rejected/Draft this way — for everyone else every row lands as Pending, same as a normal Add Expense submission.
  • Amount accepts plain numbers or values like PKR 1,250.00 — currency symbols and commas are stripped automatically.
Not supported via bulk upload — add/edit these individually instead: BOM Overhead / Manufacturing Order allocation, Monthly Division, and linking an expense to a Journal Account (Debit/Credit). An existing expense that is a BOM Overhead expense is skipped rather than modified.
