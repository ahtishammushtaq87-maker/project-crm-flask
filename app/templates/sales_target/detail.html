How this is calculated

Actual sales are the totals of approved invoices dated within the target period {%- if target.target_type == 'individual' %} where the invoice’s salesman is {{ scope_label }} {%- elif target.target_type == 'team' %} where the invoice’s salesman is a team member (each invoice counted once) {%- else %} across the whole company{% endif %}.

{% if target.has_item_scope %}

Only the selected finished items count: each item’s invoice line after its line discount, minus the same items on approved returns of that invoice (even if the return is dated later). Invoice-level tax, delivery and invoice discount are not included. Payments are not counted as sales.

{% else %}

Each invoice total is after discounts, tax and delivery. Approved sales returns are already deducted from the invoice they belong to, even if the return is dated later. Payments are not counted as sales.
