Notes

{% if target.description %}
{{ target.description }}

Actual sales are approved invoices dated within the target period {%- if target.target_type == 'individual' %} where the invoice’s salesman is {{ scope_label }} {%- elif target.target_type == 'team' %} where the invoice’s salesman is a team member (each invoice counted once) {%- else %} across the whole company{% endif %}.

{% if target.has_item_scope %}

Only the selected items count: their invoice lines after line discount, minus approved returns of them. Invoice tax, delivery and invoice discount are not included.

{% else %}

Each invoice total is after discounts, tax and delivery. Approved sales returns are already deducted from the invoice they belong to. Payments are not counted as sales.

{% endif %} {% if show_profit %}

Selling price = item line after line discount, minus returns. Cost = the item’s current warehouse cost × quantity (as in the COGS report). Profit = selling price − cost.

{% endif %}
